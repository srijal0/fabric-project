## Purpose

The documentation provides a central reference for understanding, developing,
testing, deploying, and maintaining Selvage.

It also supports the reproducibility and maintainability of the project by
recording important technical decisions and development procedures.

## Project

**Selvage — Fabric & Material Cataloging System**

The project is developed as an academic thesis prototype using a FastAPI
backend, SQLModel, SQLite, and a plain HTML/CSS/JavaScript frontend.
